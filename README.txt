防災行動ナビ v12

変更点:
- 作業データを今回提示されたapp.js相当の内容に入れ替えました。
- 非常時に日付・時刻を直接入力しなくてもよいように、「今発生」「5分前」「10分前」「30分前」「1時間前」「2時間前」「3時間前」「6時間前」「12時間前」「3日前」「7日前」から選べるようにしました。
- 選択した「○分前／○時間前／○日前」をもとに、暫定の地震発生日時を自動設定します。
- 余裕ができた段階で、日付・時刻欄から正確な発生日時に修正できます。
- やること一覧は、過ぎた作業・今やる作業・これからの作業をすべて表示します。
- 時系列の見える化は、選んだ経過時間に応じて横軸を自動で圧縮表示します。
- service-worker.js のキャッシュ名を v12 に更新しました。

GitHub Pagesへ反映する場合:
zipを解凍し、以下のファイルをリポジトリ直下に上書きアップロードしてください。

index.html
style.css
app.js
manifest.json
service-worker.js
icon.svg
README.txt

古い表示が残る場合:
Safari/Chromeで再読み込みしてください。ホーム画面アイコンから開いて古い場合は、一度ホーム画面アイコンを削除し、再度追加してください。

- 画面上部のタイトル横に「最新版に更新」リンクを追加しました。
