防災行動ナビ v15 再構築版

【公開URL】
https://terahinan.github.io/bousai-appli/

【この版について】
・正常に動作していたv15の画面構造、デザイン、Q&Aの開閉動作を基準に再構築しています。
・お父様が更新したapp14.jsの内容を反映しています。
  - 役割
  - 作業内容
  - 作業開始／終了時間
  - 対応Q&A
  - Q&A分類順
・Q&Aは、選択した「自分の立場」に関係する項目だけを表示します。
・Q&Aは「分類 → 質問 → 回答」の順に開いて確認できます。
・Question／AnswerのStatus表示は使用していません。
・iPhoneでスクロールしても、開いているQ&Aが不用意に閉じないようにしています。

【地震発生時刻の設定】
最初に、次の簡単入力から地震発生からの経過時間を選択できます。

今発生
5分前
10分前
30分前
1時間前
2時間前
3時間前
6時間前
12時間前
3日前
7日前

選択した時間をもとに、地震発生日時を暫定的に設定します。
余裕ができた段階で、正確な発生日時へ修正できます。

【app.jsを修正する場合】
作業内容を変更する場合は、app.js内の以下を編集します。

・roles
  役割の追加・削除

・tasks
  作業名、説明、注意事項、startMin、endMin、作業の追加・削除

・qandaItems
  Q&Aの分類、対象となる立場、質問、回答

・QANDA_CATEGORY_ORDER
  Q&A分類の表示順

・QUICK_OPTIONS
  「5分前」「3時間前」など簡単入力の選択肢

※画面に新しい欄や部品を追加する場合、または見た目・レイアウトを変更する場合は、
  app.js以外にindex.htmlやstyle.cssの修正が必要になる場合があります。

【GitHub Pages】
公開先：
https://terahinan.github.io/bousai-appli/

GitHub Pagesの公開設定（main / root）は、最初にSaveすれば通常は毎回変更する必要はありません。
ファイル更新後はCommit changesを実行すると、GitHub Pagesへ反映されます。

【最新版に更新】
GitHubへ新しいファイルを反映した後、インターネットへ接続した状態で
画面上部の「最新版に更新」を押してください。

更新処理では、Service Workerの更新確認と古いアプリ用キャッシュの削除を行い、
GitHub Pages上の最新版を再読み込みします。

古い表示が残る場合は、SafariまたはChromeで公開URLを直接開いて再読み込みしてください。

【オフライン利用】
一度オンラインでアプリを開くと、必要なファイルを端末に保存します。
その後はネットに接続できない場合でも表示できるようにしています。

災害時に備え、事前にホーム画面へ追加したうえで、機内モードでも開けることを確認してください。
