地震時 行動ナビ サンプル v3

■ 使い方
1. このzipを解凍します。
2. index.html をダブルクリックします。
3. ブラウザで画面が開きます。
4. 地震発生時刻と立場を選ぶと、現在までにやるべきことが表示されます。

■ 今回の特徴
- 地震発生時刻を入力できます。
- 発生からの経過時間を自動計算します。
- その時点までにやるべき作業を全部表示します。
- チェックを入れられます。
- ガントチャート風の時系列表示があります。
- オレンジ色の現在時刻線は、作業名の列ではなくメーター部分の左端から始まります。

■ 作業項目の変更方法
app.js の tasks の中を書き換えます。

例：
{
  id: "resident-001",
  role: "町民",
  startMin: 0,
  endMin: 5,
  title: "身の安全を確保する",
  detail: "机の下に入る、頭を守る。",
  note: "慌てて外へ出ない。"
}

startMin は、地震発生から何分後に始めるか。
endMin は、何分後までに終える目安か。

■ 注意
このサンプルは試作用です。
実際に使う場合は、自治体・町会・避難所の正式な防災計画に合わせて内容を確認してください。
